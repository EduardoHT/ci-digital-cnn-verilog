# CI Digital CNN: cross-validation and RTL evaluation

## Dataset protocol

- Dataset: 2,000 unique grayscale images, 28 x 28 pixels, five classes.
- Baseline split: 1,400 training (70%), 400 validation (20%), and 200 test images (10%).
- Cross-validation: the same 200-image test set was fixed and excluded from every fold. The remaining 1,800 images were divided with stratified 5-fold cross-validation, yielding 1,440 training and 360 validation images per fold.
- Training: baseline plus folds 1-5, 40 epochs per execution.

## RTL protocol

- Simulator: Icarus Verilog 13.0 (stable), SystemVerilog 2012 mode.
- Compilation: iverilog -g2012 -s tb_dataset_batch -o <simulation.vvp> rtl/cnn_accel.sv tb/tb_dataset_batch.sv.
- Runtime: vvp with batch, weight, image, label, and output plusargs generated by validate_rtl_cv.py.
- Evaluated weights: baseline and folds 1-5.
- Test set: the same fixed 200 held-out images for every weight set.
- Equivalence: RTL logits and predicted classes were compared against the integer Python reference. All six runs achieved 200/200 exact matches, totaling 1,200/1,200.
- Latency: 2,665,208 accelerator clock cycles per image, with one unique observed value in the batch test. This count is emitted by the RTL/testbench execution; the available summaries do not provide a validated per-layer decomposition.
- Metrics: accuracy, macro precision, macro recall, macro-F1, per-class precision/recall/F1, and confusion matrix. Fold standard deviations use the sample convention (ddof=1).

## Results

| Run | Accuracy | Macro-F1 | Exact RTL/Python |
|---|---:|---:|---:|
| Baseline | 89.00% | 88.8238% | 200/200 |
| Fold 1 | 86.50% | 86.4378% | 200/200 |
| Fold 2 | 90.00% | 89.7919% | 200/200 |
| Fold 3 | 86.00% | 86.0292% | 200/200 |
| Fold 4 | 93.00% | 92.9719% | 200/200 |
| Fold 5 | 93.50% | 93.5315% | 200/200 |

Mean RTL test accuracy across folds 1-5: **89.80% +/- 3.1607 percentage points**. The corresponding floating-point fold mean was 90.10% +/- 2.95 percentage points, for a mean quantization-to-RTL change of -0.30 percentage points.
